# Phiếu đánh giá chéo — chờ thực hiện

Người kiểm: __________   Ngày: __________   Phiên bản: __________

Mở sáu trang bằng máy chủ thực hành. Đi lần lượt bằng bàn phím, sau đó dùng chuột. Ghi lỗi có thể lặp lại, không chỉ nhận xét giao diện.

|---|---|---|---|---|---|---|
| Chưa kiểm | | | | | | |

1. Skip link vào main, Tab có viền và thứ tự hợp lý.
2. Tên sách, alt, heading, landmark nghe có nghĩa.
3. Form có nhãn; nhập sai được báo bằng chữ; sửa đúng gửi được.
4. Filter, dialog, giỏ nổi mở bằng phím và đóng bằng Esc; focus quay về đúng chỗ.
5. Không thiếu tài nguyên; metadata từng trang khác nhau.
6. HTML có cấu trúc ổn định, điểm gắn CSS rõ, thứ tự DOM đúng.

Phiếu này chưa có người kiểm độc lập, vì vậy chưa phải bằng chứng một buổi đánh giá chéo đã diễn ra.
