# Kiểm định GitHub

Workflow chạy kiểm tĩnh, 11 bài kiểm tra trình duyệt (sáu trang và các luồng tương tác), axe và Lighthouse cho sáu trang. Bằng chứng nằm trong artifact html-quyen-01-evidence ở lần chạy Actions của commit. Chỉ coi đạt sau khi lần chạy thực tế xanh. Không dùng báo cáo tự động để khẳng định tuân thủ hoàn toàn WCAG hoặc đã nghe screen reader.
