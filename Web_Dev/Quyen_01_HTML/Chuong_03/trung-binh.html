Bài trung bình chương 3 — Trích dẫn có nguồn

Trích ngắn từ tiêu chuẩn HTML được đặt thành khối để thể hiện cấu trúc nguồn:

The html element represents the root of an HTML document.

Tiêu chuẩn mô tả html là the root of an HTML document. Nguồn: HTML Living Standard, bản được ghi cập nhật ngày 11/11/2026; truy cập 12/11/2026.

blockquote là trích thành khối; q là trích trong câu và tự có dấu ngoặc; cite bọc tên tác phẩm; thuộc tính cite cung cấp URL nguồn, còn liên kết a giúp người đọc mở nguồn; time có giá trị ISO để máy đọc. Mỗi phần giữ nguyên vai trò, không dùng cite bọc cả đoạn. Đoạn trích cố ý ngắn, phần giải thích do người làm tự viết.
